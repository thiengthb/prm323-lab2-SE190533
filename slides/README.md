# Slide thuyết trình Lab 2 (bản web)

`index.html` là deck 14 slide, một file, không cần cài gì. Ảnh nằm trong `img/` (Figma Final UI v2, Stitch IT-0..IT-3, wireframe).

| Phím | Việc |
|---|---|
| → Space PageDown, hoặc bấm vào 2/3 bên phải | Slide tiếp |
| ← PageUp, hoặc bấm vào 1/3 bên trái | Lùi |
| N | Hiện lời nói (ghi chú người nói) ở đáy màn |
| F | Toàn màn hình |
| Ctrl+P | In ra PDF, mỗi slide một trang |

Bản đăng: GitHub Pages của repo, workflow `Slides` tự đăng lại mỗi lần sửa `slides/`.
